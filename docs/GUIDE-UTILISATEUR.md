# Guide rapide

1. Ouvre La Moula et renseigne d'abord l'onglet « Mon activité ».
2. Ajoute tes clients dans « Clients ».
3. Crée un devis ou une facture depuis « Nouveau document ».
4. Ajoute les prestations, quantités, prix HT et taux de TVA. Le total se calcule automatiquement.
5. Enregistre puis choisis « PDF / Imprimer » sur la fiche du document. Dans la fenêtre d'impression, sélectionne « Enregistrer au format PDF ».
6. Pour marquer une facture réglée, utilise « Marquer payée ».
7. Fais régulièrement une sauvegarde JSON depuis « Mon activité ».

Pour retrouver les mêmes données sur plusieurs appareils, configure Supabase selon le README, puis connecte-toi avec le même compte sur chaque appareil.
